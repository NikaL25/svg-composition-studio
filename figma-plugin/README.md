# Illustration Composition Builder — Figma Plugin

Это отдельный Figma Plugin-проект. Он не создаёт вымышленные иллюстрации: сканирует реальные узлы страницы `Библиотека компонентов`, показывает только найденные компоненты и клонирует исходные Figma-ноды без перерисовки геометрии.

## Возможности

- сканирование секций `Размер L` и `Размер S`;
- фильтр по уровню детализации и названию;
- добавление реального узла библиотеки на текущую страницу;
- создание холста квадратного, портретного или ландшафтного формата;
- экспорт выбранного узла в SVG;
- дальнейшее расширение для палитр, слоёв и AI-подбора поверх реальных node ID.

## Запуск

```bash
npm install
npm run build
```

В Figma: `Plugins → Development → Import plugin from manifest...` и выбрать [manifest.json](./manifest.json). Для разработки используйте `npm run watch`.
