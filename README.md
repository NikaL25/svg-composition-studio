# SVG Composition Studio

Проект включает две независимые части:

1. `src/` — самостоятельное React-приложение-редактор.
2. `figma-plugin/` — отдельный Figma Plugin для поиска и копирования настоящих компонентов из открытого Figma-файла.

React-приложение не зависит от Figma во время работы. Плагин и React-приложение не запускаются одной командой и не используют общий runtime.

## 1. Что находится в проекте

```text
New folder/
├── src/                    React-приложение
├── svg/                    исходная SVG-библиотека, автоматически загружаемая приложением
├── figma-plugin/           Figma Plugin
├── components.catalog.json архивный каталог из аудита Figma
├── SOURCE_AUDIT.md         отчёт об исследовании Figma
├── package.json            зависимости React-приложения
└── README.md               эта инструкция
```

### React-приложение

Основной файл интерфейса — [src/main.tsx](./src/main.tsx).

Вспомогательные модули:

- [src/importer.ts](./src/importer.ts) — импорт SVG и ZIP;
- [src/svg.ts](./src/svg.ts) — SVG-метрики, безопасный разбор и палитры;
- [src/project.ts](./src/project.ts) — сохранение и загрузка проекта;
- [src/ai.ts](./src/ai.ts) — локальный подбор компонентов;
- [src/catalog.ts](./src/catalog.ts) — сканирование SVG через Vite `import.meta.glob`.
- [src/layout.ts](./src/layout.ts) — начальная автоматическая компоновка объектов.

При запуске все SVG из `svg/L|S/main_objects` и `svg/L|S/background_objects` загружаются автоматически. Каждая запись сохраняет уровень детализации, роль, исходный путь и уникальный ID. `components.catalog.json` оставлен как архив аудита и приложением не используется.

### Figma Plugin

Исходники плагина находятся в [figma-plugin/](./figma-plugin).

- [figma-plugin/src/code.ts](./figma-plugin/src/code.ts) — код Figma API;
- [figma-plugin/src/ui.html](./figma-plugin/src/ui.html) — интерфейс плагина;
- [figma-plugin/manifest.json](./figma-plugin/manifest.json) — манифест для загрузки в Figma;
- [figma-plugin/build.mjs](./figma-plugin/build.mjs) — сборка плагина.

Плагин работает непосредственно внутри Figma Desktop и использует Figma Plugin API. Он не подключён к React-приложению и не загружает библиотеку из `components.catalog.json`.

## 2. Требования

Установите:

- Node.js 20 или новее;
- npm;
- Figma Desktop для проверки плагина.

Проверка установки:

```bash
node --version
npm --version
```

Если команды не найдены, сначала установите Node.js с официального сайта: <https://nodejs.org/>.

## 3. Запуск React-приложения

Откройте PowerShell или терминал в корневой папке проекта:

```bash
cd "C:\Users\User\Desktop\New folder"
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite, обычно:

```text
http://localhost:5173
```

Остановить приложение можно клавишами `Ctrl + C`.

## 4. Быстрая демонстрация React-приложения

Используйте этот сценарий при показе работодателю.

### Шаг 1. Проверить каталог

1. Откройте приложение.
2. Слева автоматически отображается каталог доступных SVG с превью, размером и ролью.
3. Переключите L/S и фильтры «Основные»/«Фоновые».
4. Добавьте объект нажатием на карточку.

### Шаг 2. Добавить дополнительные SVG (необязательно)

1. Нажмите `Дополнительный импорт`.
2. Выберите один или несколько `.svg` либо `.zip` с SVG.
3. Можно также перетащить файл в область импорта.
4. Имена и пути импортированных файлов сохраняются отдельно; одноимённые компоненты не перезаписывают друг друга.
5. Нажмите на компонент — он появится в центре холста.

### Шаг 3. Проверить редактор

Проверьте по очереди:

1. Перетащите объект мышью.
2. Выберите объект на холсте.
3. Измените `Позиция X` и `Позиция Y`.
4. Измените масштаб ползунком.
5. Измените поворот.
6. Измените непрозрачность.
7. Добавьте ещё один объект.
8. В панели `Слои` измените порядок объектов.
9. Нажмите на значок видимости слоя.
10. Удалите выбранный объект.

### Шаг 4. Проверить клавиатурное управление

Выберите объект и используйте:

- стрелки — перемещение на 5 px;
- `Shift + стрелка` — перемещение на 20 px;
- `R` — поворот на 15 градусов;
- `Ctrl + D` — дублировать выбранный объект;
- `Delete` или `Backspace` — удалить объект;
- `Escape` — снять выделение.

### Шаг 5. Проверить детализацию и форматы

1. Переключите `L` и `S` в верхней панели.
2. Убедитесь, что каталог фильтруется по уровню детализации.
3. Переключите `Квадрат`.
4. Переключите `Портрет`.
5. Переключите `Ландшафт`.
6. Убедитесь, что размеры холста и подпись внизу меняются.

### Шаг 6. Проверить цветовую схему

1. В панели `Цветовые схемы` нажмите `＋`.
2. Схема создаётся пустой, без выдуманных значений.
3. Введите пару точных цветов из исходного SVG и желаемый новый цвет.
4. Убедитесь, что перекраска меняет векторные атрибуты цвета, сохраняя геометрию.

### Шаг 7. Проверить сохранение проекта

Есть два варианта:

1. Нажмите `Сохранить проект` — скачается `composition-project.json`.
2. Нажмите `Открыть проект` и выберите ранее сохранённый JSON.
3. Проверьте, что восстановились компоненты, позиции, слои и палитры.

Дополнительно приложение автоматически сохраняет состояние в `localStorage` браузера. После перезагрузки страницы проект восстанавливается.

### Шаг 8. Проверить SVG-экспорт

1. Добавьте минимум один объект.
2. Настройте его положение, размер и поворот.
3. Нажмите `Экспорт SVG`.
4. Откройте скачанный `composition.svg` в браузере или в Figma.
5. Убедитесь, что это редактируемый SVG, а не растровая картинка.

## 5. Проверка локальной автокомпоновки

1. В правой панели найдите `Автокомпоновка`.
2. Введите метафору, например `Образование и саморазвитие`, либо названия `Книга, наушники, ваза`.
3. Нажмите `Собрать композицию`.
4. Объекты появятся на холсте; отредактируйте их вручную или нажмите `Перекомпоновать`.

Подбор работает локально по названиям и семантическим алиасам; внешний AI API не подключён. Для фонового варианта укажите «фон» в запросе. Используются только доступные SVG текущего размера.

## 6. Запуск и проверка Figma Plugin

Перейдите в папку плагина:

```bash
cd "C:\Users\User\Desktop\New folder\figma-plugin"
npm install
npm run build
```

Плагин и веб-приложение собираются отдельно. После сборки плагина в Figma Desktop:

1. Откройте нужный Figma-файл.
2. Выберите `Plugins → Development → Import plugin from manifest...`.
3. Укажите файл [figma-plugin/manifest.json](./figma-plugin/manifest.json).
4. Запустите плагин через `Plugins → Development`.
5. Убедитесь, что в файле есть страница с точным названием `Библиотека компонентов`.
6. На этой странице создайте секции с точными названиями `Размер L` и/или `Размер S` и поместите в них компоненты.
7. Нажмите `Сканировать`. Плагин обходит узлы секций рекурсивно через технические группы и показывает узлы с семантическими именами.
8. Фильтруйте найденные компоненты по названию и уровню `L/S`.
9. Нажмите на компонент, чтобы клонировать его на текущую страницу около центра видимой области.
10. При необходимости создайте отдельный пустой белый холст формата квадрат, портрет или ландшафт.
11. Выберите узел или холст на странице и нажмите `Экспорт выбранного SVG`.

Для разработки с автоматической пересборкой:

```bash
npm run watch
```

После изменений перезапустите плагин в Figma.

### Что именно делает плагин

- Сканирует страницу `Библиотека компонентов` и её секции `Размер L`/`Размер S`, включая вложенные технические группы.
- Показывает реальные узлы, отфильтрованные по уровню детализации и названию.
- Клонирует выбранный узел на текущую страницу Figma. Исходный узел не перерисовывается.
- Создаёт отдельный пустой белый Frame выбранного формата.
- Экспортирует первый выделенный на текущей странице узел в SVG.

Клонированный узел и новый Frame добавляются на страницу по отдельности: плагин автоматически не помещает компонент внутрь Frame. Составление макета, сохранение проекта, управление слоями, перекраска и AI-поиск в самом Figma Plugin не реализованы. Поиск в его окне — это фильтр уже просканированных имён.

## 7. Что проверять работодателю

Минимальный сценарий проверки занимает несколько минут:

1. Запустить React-приложение через `npm run dev`.
2. Убедиться, что автоматически отображается 39 SVG.
3. Добавить объекты из основных и фоновых вариантов.
4. Переместить и повернуть объект.
5. Проверить слой и видимость.
6. Переключить формат холста.
7. Создать палитру.
8. Сохранить проект в JSON.
9. Загрузить JSON обратно.
10. Экспортировать итог в SVG.

Если требуется проверить именно интеграцию с Figma:

1. Собрать плагин через `npm run build` в папке `figma-plugin`.
2. Загрузить [manifest.json](./figma-plugin/manifest.json) в Figma Desktop.
3. Подготовить страницу и секции с точными именами, указанными выше.
4. Запустить сканирование библиотеки.
5. Клонировать найденный узел на текущую страницу.
6. Выбрать этот узел и экспортировать его в SVG.

## 8. Ограничения текущей версии

- Все 39 SVG из текущей библиотеки входят в статическую сборку приложения.
- Для «Кошелек» отсутствует вариант L в категории фоновых объектов; при переключении размера приложение сохраняет существующий вариант и сообщает об отсутствии.
- Точные три оригинальные цветовые схемы не заданы, поэтому они не предустановлены.
- Внешний AI-провайдер не подключён.
- React и Figma Plugin запускаются отдельно.
- Figma Plugin зависит от точных названий страницы и секций, а также от именования узлов.
- Figma Plugin создаёт пустой Frame и клонирует компоненты отдельно. Автоматической раскладки компонентов на Frame нет.
- Перед экспортом из плагина нужно выделить узел или Frame в Figma; экспортируется только первый выделенный узел.
- Для запуска и production-проверки требуется установленный Node.js.

Исходные SVG лежат в [svg/](./svg). [SOURCE_AUDIT.md](./SOURCE_AUDIT.md) и [components.catalog.json](./components.catalog.json) содержат прежние результаты исследования Figma и не являются источником данных React-каталога.
