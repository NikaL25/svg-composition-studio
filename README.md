# ✦ SVG Composition Studio

**Интеллектуальный веб-конструктор векторных иллюстраций из готовой библиотеки SVG-компонентов.**

🔗 **Live Demo:** [https://example.com](https://example.com) *(демо-стенд приложения)*  
📦 **Репозиторий:** `https://github.com/NikaL25/svg-composition-studio.git`

---

## О проекте

**SVG Composition Studio** — это веб-сервис и плагин для Figma, позволяющие собирать сбалансированные редакционные и продуктовые иллюстрации исключительно из оригинальной векторной библиотеки компонентов (элементы **20 исходных иллюстраций** в двух уровнях детализации `L` и `S`).

Ключевой принцип системы — **100% сохранность авторской векторной графики**:
- Сервис **не генерирует** новые иллюстративные контуры нейросетью и **не растеризует** графику в PNG/JPEG.
- Каждый объект остаётся чистым набором оригинальных `<path>` с сохранением пропорций.
- Семантический движок и AI используются **только** для понимания смысла запроса, подбора совместимых объектов из существующего каталога и расчёта сбалансированной композиции.
- Итоговый файл экспортируется в **полностью редактируемый по слоям SVG**, готовый к открытию в **Figma**, **Adobe Illustrator** или браузере.

Проект состоит из двух независимых частей:
1. **Веб-приложение (`src/`)** — интерактивный векторный редактор композиций на React + TypeScript.
2. **Figma Plugin (`figma-plugin/`)** — плагин для Figma Desktop для сканирования библиотеки документа, клонирования оригинальных узлов и экспорта SVG.

## Технологический стек

| Слой | Технологии и инструменты | Назначение в проекте |
|---|---|---|
| **Frontend Core** | **React 18**, **TypeScript 5.7** (`strict`) | Управление состоянием сцены, интерактивный SVG-холст, инспектор свойств, слои |
| **Сборка и статика** | **Vite 6** (`import.meta.glob`) | Автоматическое обнаружение и ленивая подгрузка 39 оригинальных `.svg` без раздувания JS-бандла |
| **Векторное ядро** | **Browser DOM API** (`DOMParser`, `XMLSerializer`, CSSOM) | Безопасная санитизация SVG, ролевая перекраска атрибутов/стилей/градиентов, скоупинг `id` и экспорт в чистый векторный XML |
| **Семантика и AI** | Собственный морфологический движок + опциональный REST/Gemini адаптер | Русско-английский стемминг, граф бизнес-метафор, матрица смысловой совместимости объектов и строгий whitelist `assetId` |
| **Алгоритм компоновки** | Кастомный геометрический движок (`layout.ts`) | Сохранение эталонных пропорций, 4 композиционные схемы, разрешение пересечений (AABB relaxation) и контроль границ |
| **Архивы и хранение** | **JSZip**, `localStorage`, JSON Snapshot v1 | Импорт `.svg` и `.zip`-архивов, автосохранение с `debounce` и переносимые файлы проектов |
| **Интеграция с Figma** | **Figma Plugin API**, **esbuild** | Автономный плагин для работы напрямую с узлами открытого Figma-документа |

## Быстрый старт и установка

### Предварительные требования
- **Node.js 20+** и **npm** (проверка: `node -v` и `npm -v`)
- Современный браузер (Chrome, Edge, Firefox, Safari)
- *(Опционально)* **Figma Desktop** — если планируете тестировать Figma-плагин

### 1. Клонирование и запуск веб-приложения

```bash
git clone https://github.com/NikaL25/svg-composition-studio.git
cd svg-composition-studio
npm install
npm run dev
```

После запуска откройте в браузере локальный адрес, который выведет Vite (обычно `http://localhost:5173`).

### 2. Проверка типов и production-сборка

```bash
npm run build
npm run preview
```

Команда `npm run build` выполняет строгую проверку TypeScript (`tsc -b`) и собирает оптимизированный бандл в `dist/`, сохраняя все 39 векторных компонентов как отдельные статические `.svg`-ресурсы.

### 3. Опциональная настройка внешнего AI-провайдера (`.env`)

По умолчанию приложение полностью автономно и работает на встроенном локальном семантическом движке (`СЕМАНТИКА`), не требуя ключей API. При желании можно подключить внешний совместимый провайдер в `.env`:

```env
VITE_AI_BASE_URL=https://generativelanguage.googleapis.com/v1beta
VITE_AI_API_KEY=ВАШ_API_КЛЮЧ
VITE_AI_MODEL=gemini-2.5-flash
```
*(Внешний AI получает только текстовые метаданные существующего каталога и может возвращать только существующие `assetId`; при отсутствии ключа или сети сервис бесшовно использует локальный подбор).*

### 4. Сборка и запуск Figma Plugin (отдельно от веб-приложения)

```bash
cd figma-plugin
npm install
npm run build
```

1. Откройте **Figma Desktop** и документ со страницей `Библиотека компонентов` (содержащей секции `Размер L` и `Размер S`).
2. Перейдите в меню **Plugins → Development → Import plugin from manifest...** и выберите файл `figma-plugin/manifest.json`.
3. Запустите плагин из **Plugins → Development → Illustration Composition Builder**.

## Пошаговый гайд по тестированию всех функций (5–7 минут)

Ниже приведён полный чек-лист, по которому любой проверяющий может протестировать все требования системы прямо в браузере:

### Шаг 1. Проверка SVG-библиотеки и фильтрации
1. Откройте веб-приложение — в верхней строке статуса отобразится загрузка **39 оригинальных SVG-компонентов**.
2. В левой панели проверьте фильтры для размера **L**: `Все (19)`, `Главные (10)`, `Фоновые (9)`.
3. На верхней панели холста переключите размер на **S · Компактный** — счётчики обновятся на `Все (20)`, `Главные (10)`, `Фоновые (10)`.
4. Введите в поиск слева `книга` или `знания` — поиск работает как по названиям объектов, так и по семантическим ключевым словам.

### Шаг 2. Сценарий 1 — Автосборка по метафоре или заголовку
1. В правой панели в блоке **«Автосборка композиции»** выберите вкладку **«По метафоре»**.
2. Нажмите на любой из готовых пресетов или введите свой запрос:
   - `Цифровая трансформация бизнеса`
   - `Командная работа`
   - `Рост и развитие`
   - `Искусственный интеллект`
   - `Безопасность данных`
3. На холсте автоматически соберётся сбалансированная композиция из смыслово совместимых главных и фоновых объектов, а под кнопкой появится список выбранных объектов с пояснением роли каждого из них.
4. Снимите галочку **«Добавлять монохромные фоновые объекты»** и нажмите **«Собрать композицию»** ещё раз — композиция соберётся исключительно из цветных главных объектов.

### Шаг 3. Сценарий 2 — Сборка по конкретным названиям компонентов
1. Переключите вкладку автосборки на **«По компонентам»**.
2. Введите в текстовое поле:
   ```text
   Книга, Лампа, Папка (фон)
   ```
   и нажмите **«Собрать из выбранных»** — на холсте разместятся ровно эти три объекта в указанных ролях.
3. Проверьте обработку несуществующих объектов — введите:
   ```text
   Книга, Космический корабль, Дракон
   ```
   Сервис разместит найденную `Книгу` и выведет явное предупреждение: *«Не найдены в библиотеке (без замены): Космический корабль, Дракон»*, не подменяя отсутствующие элементы случайными картинками.

### Шаг 4. Автокомпоновка и перебор композиционных схем
1. Нажмите кнопку **«↻ Перекомпоновать»** на верхней панели над холстом несколько раз.
2. Текущие объекты на холсте будут аккуратно перестраиваться по 4 композиционным схемам (*Сбалансированная → Фокусная → Диагональная → Арочная*) без хаотичных наложений и выхода за границы холста.
3. Переключите формат холста (**Квадрат 1080×1080**, **Портрет 1080×1350**, **Ландшафт 1200×675**) и нажмите **«↻ Перекомпоновать»** — раскладка адаптируется под пропорции нового формата.

### Шаг 5. Переключение двух размеров детализации (`L ↔ S`)
1. Разместите несколько объектов на холсте в размере **L · Детальный**.
2. Переключите размер на **S · Компактный** в тулбаре холста.
3. Все объекты заменятся на соответствующие S-векторы меньшей детализации, но **сохранят свой точный визуальный размер, позицию и баланс композиции** благодаря пропорциональному пересчёту коэффициента масштаба.
4. *Особый кейс*: добавьте фоновый `Кошелек` в размере `S` и переключитесь на `L` — так как отдельного файла `L/background_objects/Кошелек.svg` в исходной библиотеке нет, сервис не смешает S и L детализацию, а применит оригинальный L-вектор «Кошелька» в строгом монохромном фоновом режиме и выведет честное уведомление.

### Шаг 6. Переключение роли объекта «Главный ↔ Фоновый»
1. Кликните по любому объекту на холсте.
2. В правой панели в блоке **«Свойства объекта»** переключите его роль с **«Главный (цветной)»** на **«Фоновый (монохром)»** и обратно.
3. Объект мгновенно сменит вариант на монохромный (и обратно на цветной), сохранив координаты, масштаб, поворот и позицию в слоях.

### Шаг 7. Ролевые цветовые схемы и защита правил палитры
1. В блоке **«Цветовые схемы»** переключайте 3 предустановленные схемы:
   - `★ Лавандовая (Оригинал)`
   - `★ Шалфей и Терракота`
   - `★ Океан и Янтарь`
2. Обратите внимание: перекрашивается вся композиция целиком и превью в каталоге. Главные объекты используют акцентные + фоновые тона (сохраняя контур `#181817` и белые блики `#FFFFFF`), а фоновые объекты остаются **строго монохромными**.
3. Нажмите `＋`, чтобы создать пользовательскую схему: поменяйте цвета ролей через палитру. Если попытаться назначить фоновой роли акцентный цвет главного объекта — сработает встроенная валидация, блокирующая нарушение цветовой системы.

### Шаг 8. Ручное редактирование и горячие клавиши
- **На холсте**: перетаскивайте объекты мышью, тяните за **4 угловых маркера** для строго пропорционального масштабирования, вращайте за **верхний круглый маркер** (зажмите `Shift` для привязки угла к шагу `15°`).
- **В панели «Слои»**: меняйте порядок наложения кнопками `↑` / `↓`, инвертируйте слои `⇅` или скрывайте объекты значком `◉`.
- **С клавиатуры** (при выделенном объекте):
  - `←` `↑` `→` `↓` — сдвиг на `5 px` (`Shift + стрелка` — на `20 px`)
  - `R` — поворот на `+15°`
  - `Ctrl + D` / `Cmd + D` — дублирование объекта
  - `Delete` / `Backspace` — удаление объекта
  - `Escape` — снятие выделения

### Шаг 9. Сохранение проекта и экспорт редактируемого SVG
1. Нажмите **«Сохранить JSON»** — скачается портативный снимок `composition-project.json`. Перезагрузите страницу (проверит автовосстановление из `localStorage`) или откройте JSON кнопкой **«Открыть JSON»**.
2. Нажмите **«Экспорт SVG»** — скачается файл `composition-L-square.svg`.
3. Перетащите скачанный `.svg` в **Figma** или откройте его как текст: внутри нет ни одного растрового `<image>`, а каждый видимый объект оформлен отдельной именованной векторной группой `<g id="layer-..." data-name="...">` со всеми оригинальными `<path>`.
