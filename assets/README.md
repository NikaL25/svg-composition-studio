# Дополнительные SVG

Основная библиотека находится в `../svg/` и автоматически загружается React-приложением через Vite. Она организована по размеру (`L`, `S`) и роли (`main_objects`, `background_objects`).

Папку `assets/` можно использовать для дополнительных ресурсов. Отдельные SVG и ZIP с SVG также можно импортировать через интерфейс редактора; исходный путь архива сохраняется в метаданных импортированного объекта.
